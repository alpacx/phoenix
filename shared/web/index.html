Port forwarding.

Inoltra una porta d’ingresso verso un dispositivo della rete protetta.

Una mappatura locale non apre le porte del provider.

I server NordVPN standard non supportano connessioni in ingresso. Con altri tunnel o in modalità diretta serve anche l’inoltro sul router/provider a monte. Le risposte devono rispettare le regole in uscita.

IL TUO TUNNEL

VPN WireGuard.

WireGuard è un protocollo VPN: crea una connessione cifrata tra Phoenix e un server VPN. Importa il profilo fornito dal tuo servizio VPN o dall’amministratore del server.

—

Collega la tua VPN

Hai un abbonamento NordVPN? Usa la sezione NordVPN per la configurazione guidata. Qui puoi usare un altro servizio compatibile con WireGuard o un server gestito da te.

Un peer, IPv4, endpoint numerico, DNS singolo. MTU 1280–1420. Chiavi salvate sul dispositivo e mai restituite dalle API.

Escludi paesi con restrizioni VPN

Evita queste destinazioni nella scelta casuale e manuale.

Quali paesi vengono esclusi?

Cina, Russia, Bielorussia, Turchia, Iraq, Emirati Arabi Uniti, Oman, India, Iran, Egitto, Turkmenistan, Corea del Nord, Uganda, Myanmar, Arabia Saudita e Venezuela.

Filtro Phoenix basato sui paesi con divieti, restrizioni o limitazioni descritti da NordVPN. Riguarda l’uso delle VPN in quei paesi: non è una valutazione di sicurezza dei server NordVPN. Alcune destinazioni sono virtuali.

Rotazione automatica

Cambia paese in modalità casuale, oppure server nel paese selezionato.

Da 30 a 86400 secondi. Il timer parte dal tunnel connesso. Cambiare server può interrompere download, chiamate e sessioni; l’IP pubblico potrebbe rimanere lo stesso.

ROTATION CONTROL

Rotazione automatica disattivata.

Il paese è un vincolo.

Se selezioni un paese, Phoenix non uscirà altrove. Quando non trova un server utilizzabile, blocca il traffico e riprova.
