1.47inch LCD Display Module With Touch panel, Micro LCD Display, 172×320 Resolution, IPS, SPI And I2C Communication, 262K Display Color
1.47inch Touch LCD Display Module

Embedded JD9853 driver and AXS5106L capacitive touch control chip

Comes with examples for Raspberry Pi, ESP32S3, Pico, Arduino, etc.



  • Size1.47"
  • Resolution172×320
  • Display Color262K
  • Display PanelIPS

  • Display DriverJD9853
  • Display InterfaceSPI
  • Touch DriverAXS5106L
  • Touch InterfaceI2C
Features at a glance
  • 172×320 resolution, 262K colors, clear and colorful displaying effect
  • High touch screen transmittance, fast response and long lifetime
  • Embedded JD9853 driver chip and AXS5106L capacitive touch control chip, using SPI and I2C communication respectively, minimizes required IO pins, supports controller boards like Raspberry Pi / ESP32S3 / Raspberry Pi Pico / Arduino
  • Comes with online development resources and manual (examples for Raspberry Pi / ESP32S3 / Raspberry Pi Pico / Arduino)
